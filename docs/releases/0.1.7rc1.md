# AFK AI Friend Beta 0.1.7rc1

`0.1.7rc1` is a **Friend Beta release candidate**, not a stable release and not a GitHub Release. The current GitHub `releases/latest` entry is still `v0.1.5`; Friend Beta distribution uses the pinned AFK AI website/bootstrap path instead.

## What this candidate is

The candidate is the current Windows-first clean-machine test target. It includes the guided bootstrapper, hardware capability vetting/model selection, local Ollama + Open WebUI stack, optional SearXNG web search, local voice support, health/diagnostic tooling, and the project's loopback-first network boundary.

The first Friend Beta clean-machine run has **not yet completed the entire install-to-chat path**. It reached Python setup, model selection, and Docker Desktop installation, then Docker reported that virtualization support was unavailable. That failure is now a known installer UX gap rather than a completed fix.

## Current requirements

- Windows 11
- Hardware virtualization enabled for the Docker/WSL path
- NVIDIA GPU for the primary accelerated Friend Beta target; smaller CPU-only models are a slow fallback
- Roughly 40 GB of free disk for a comfortable first install
- Docker Desktop / WSL 2
- Ollama
- Python 3.12+
- PowerShell 7; the bootstrapper can install it when missing

Docker Desktop may require a first launch, Windows feature setup, terms acceptance, or a Windows restart. AFK AI does not require a Docker Hub sign-in for the local stack.

## Known limitation: virtualization / WSL / Docker preflight

The current installer checks Docker too late and does not yet distinguish, before setup work begins, between:

- firmware virtualization being disabled;
- a Windows virtualization feature being missing;
- WSL being absent or needing an update;
- Docker being absent;
- Docker being installed but not running;
- a required reboot;
- an unknown platform blocker.

As a result, a clean-machine install can reach Docker Desktop before the actionable Windows blocker is known. The next installer milestone is an early, resumable preflight that classifies that state, gives one precise recovery action, persists a checkpoint, and revalidates after the user fixes or reboots the machine.

## Privacy and network boundary

Local model inference can remain on the user's machine, and Open WebUI stores its local account/chat database there. Network activity is still expected for software and model downloads, updates, explicitly enabled web search, and any optional online integration the user chooses.

AFK AI should not be described as "nothing ever leaves your PC". It is local-first, not permanently offline.

## Windows security

The Friend Beta is not a signed production installer. Windows may therefore warn about the downloaded script. Do not permanently disable Defender, Smart App Control, antivirus, UAC, or other Windows protections just to install the beta. The source is public and the bootstrap/download path is integrity-pinned so it can be inspected before execution.

## Upgrade expectations

This is release-candidate software. Installer state and internal `localai` package/command names may evolve before a stable release. Do not infer stable API or migration guarantees from the Friend Beta version label.

No GitHub Release should be published from this draft without a separate release review and clean-machine acceptance decision.
