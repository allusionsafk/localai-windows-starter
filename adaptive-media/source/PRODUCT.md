# Adaptive Media

## Register
Product: native Windows media playback application.

## Users and purpose
Friends and ordinary Windows users choose a file and understandable playback enhancements. Defaults must be dependable; unsupported requests must have a visible explanation.

## Design principles
Preserve the established Windows controls, Segoe UI typography, restrained blue header and neutral surfaces. Keep media actions and playback choices prominent. Disclose hardware detail progressively. Preserve keyboard access, readable contrast, DPI-aware sizing and wrapped copy. Avoid primary-interface mpv jargon, console windows, unsupported format claims and misleading requested-as-active states.
